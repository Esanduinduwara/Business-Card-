# Personal Business Card

This is a simple personal business card website created as part of my journey in learning web development.

The project presents my personal and professional information in a clean, modern card-style layout.

## About the Project

The purpose of this project was to practice the fundamentals of **HTML and CSS** by building a small project from scratch.

The card includes:

* My name
* My role as a Full Stack Developer
* My location
* My university and degree
* Some of my technical skills
* A personal profile image

## Technologies

This project was built using only:

* HTML5
* CSS3

No JavaScript, frameworks, or external libraries were used.

## CSS Concepts Practiced

While creating this project, I practiced several CSS concepts, including:

* Flexbox
* Gradients
* Background styling
* Borders
* Border radius
* Box shadows
* Padding and margins
* CSS transitions
* Hover effects
* Responsive design
* Media queries
* `vh` units
* Glassmorphism styling

## HTML Concepts Practiced

The project also helped me practice:

* HTML document structure
* Headings
* Paragraphs
* Images
* Classes
* Linking an external CSS file
* Semantic organization of content

## How to Run

No installation is required.

Simply download or clone the repository and open `index.html` in a web browser.

```bash
git clone https://github.com/your-username/personal-business-card.git
```

Then open:

```text
index.html
```

in your browser.
